# JSONUI schema bundle

This folder contains JSON Schema (Draft-07) files generated by the editor to
help external tools (validators, editors) provide auto-completion and
conservative validation hints.

## Files

- `jsonui-element.schema.json`
  - Union schema for the element types supported by the current editor build.
    See `jsonui-metadata.json` for the generated, version-matched list.

- `jsonui-screen.schema.json`
  - Screen file schema. References the element schema via a relative `$ref`.

- `jsonui-ui_defs.schema.json`
  - Schema for `ui/_ui_defs.json`.

- `jsonui-global_variables.schema.json`
  - Schema for `ui/_global_variables.json` (supports both wrapped and bare formats).

- `jsonui-metadata.json`
  - Non-schema metadata (supported types + editable properties per type).

- `index.json`
  - Lightweight index pointing to the generated files.

## Regenerating

From the `editor-core` project root:

```bash
node scripts/generate-schemas.mjs
```

## Important limitations

- This is **not** a full Bedrock engine specification.
- Unknown fields are allowed (most objects use `additionalProperties=true`) to
  reduce false positives on real-world packs.
- Schema acceptance does not establish native property support in a particular
  parent context. The preview collection gate separately diagnoses authored
  `collection_index` below non-collection parents. Mojang's official
  [`store_common.json`](https://github.com/Mojang/bedrock-samples/blob/main/resource_pack/ui/store_common.json)
  demonstrates fixed indices as immediate `collection_panel` children.
  Materialized preview grid/factory metadata is internal, and must not be
  exported as a native declaration. Future unknown fields remain preserved.
