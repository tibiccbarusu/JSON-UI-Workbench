# 編集画面の使い方（0.12.2）

## 画面と要素を選ぶ

1. 起動 BAT からサイトを開き、左の「画面を選ぶ」でパックを読み込みます。
2. ファイルと、その中の UI 定義を選びます。同じファイルに複数の定義がある場合も選択できます。
3. 「選択した UI をプレビュー」で表示を確認し、上部の「編集」に切り替えます。
4. 左の「要素と重なり」で部品を選びます。展開矢印は親子関係を開閉する操作です。名前の検索と「前へ／次へ」でも探せます。

Pocket 用の定義は読み込み・一覧表示のみです。プレビューするときは Classic の定義を選択してください。

## 写真やボタンを動かす

キャンバスのドラッグでは、選択した部品を動かします。画像を選んだだけで親の入力欄や画面全体へ変更先を切り替えません。

ボタン全体を移動したい場合は、先に左の一覧でボタンの親要素を選びます。ボタン内部の画像だけを動かすと、クリックできる範囲は元の場所に残る場合があります。

Shift を押しながらクリックすると複数選択できます。要素一覧から選ぶと、明示的な単体選択になります。Canvas では既存のグループも利用できます。

## 位置とサイズを入力する

右の「プロパティ」に横位置・縦位置・幅・高さを表示します。数値を入力し、「位置を変更」または「サイズを変更」を押してください。

比率、変数、計算式が設定されている場合は、単純な数値に置き換えません。「属性を詳しく編集」で設定を確認してください。共有元に変更を加えるときは、適用範囲の説明も確認してください。

## 誤って動かさないようにする

要素一覧の右端のボタン、またはプロパティの「位置とサイズをロック」を使います。ロック中も一覧から選択して内容を確認できます。

親をロックすると、その中の要素の移動も止まります。子をロックしたまま親全体を動かすこともできません。必要なときは一覧の鍵から解除してください。

ロックは、このブラウザーで作業している間の誤操作防止です。書き出す Minecraft のパックへは保存されません。直接 JSON 全文を編集する操作は、通常の位置操作とは別に原文を変更します。

## 重なりを変える

要素を 1 つ選択し、「最前面へ」または「最背面へ」を押します。同じ親の中で、その要素と子要素をまとめて前後へ移動します。親子関係は変わりません。

複数選択の重なり変更はできません。重なり順が変数や計算式で指定されている場合は、詳しい属性を確認してください。動作中に重なりが変わる画面では、別の状態でも表示を確認してください。

## 変更を確定して書き出す

配置した直後は、未確定の変更としてプレビューに表示されます。「JSON UIに確定」で作業中のパックへ反映し、「書き出し」からファイルとして保存します。

「元に戻す／やり直す」で変更を確認できます。「変更の管理」には草稿の再計算と、未確定の変更を破棄する操作があります。

確定の結果を確認できなかった場合は「確定済みの内容を確認」を使ってください。同じ変更を繰り返し送信する操作にはなりません。

## 画面を広く使う

- 「コマンドを畳む」で上部を小さくできます。別のタブを選ぶと内容を開きます。
- 左右パネルを閉じても、キャンバス上部の「要素」「プロパティ」から開き直せます。
- 「画面に合わせる」「最大化」を利用できます。最大化中も下部の処理状況は表示します。
- 狭い画面では左右のパネルを片方ずつ開きます。

## 処理中かどうかを確認する

下部には処理の名前と経過秒を表示します。総数が分かる工程だけ % と件数を表示します。% はその工程の進捗なので、別の工程へ進むと数値が変わる場合があります。

30 秒以上は「処理に時間がかかっています」と表示します。処理が停止したと断定する表示ではありません。「状況を確認」からログへ移動できます。

問題が繰り返す場合は、診断タブの「ログを一括保存」を使ってください。選択した要素、ロック、未確定の変更、実行中工程などの情報も保存されます。プレビューの表示が近くても、実機での文字・テクスチャ・動作確認は引き続き必要です。
