# JSON UI Workbench 0.16.1 — 実験版 GUI 操作ガイド

`npm run gui` で明示して起動します。0.16.1 の標準入口は CLI です。
`npm start` はブラウザーを開きません。CLI / API は [入口ガイド](docs/release/ENTRYPOINTS_JA.md) を参照してください。

この GUI は、プレビューと PowerPoint のような編集を目指した実験版です。編集機能は
未完成で、共有定義・継承・生成行に関係する移動や削除が意図どおり独立しない場合が
あります。操作後に原文・診断・書出しを確認してください。CLI / API を使うために
この画面を起動する必要はありません。

起動の細部は [GUI 起動ガイド](local-node/START-ja.md)、CLI は [コマンドガイド](local-node/CLI-ja.md) を
参照してください。元版 r41 の内部ファイル名や通信識別子は互換性のため残しています。

[新しい日本語説明書](docs/release/manual/USER_GUIDE_JA.md) · [English user guide](docs/release/manual/USER_GUIDE_EN.md) · [注意事項](docs/release/manual/LIMITATIONS_JA.md)

## パックと画面を選ぶ

ZIP / MCPACK / MCADDON 内のリソースパックを読み込みます。複数の RP が含まれる
場合は対象を選びます。ビヘイビアーパックの JavaScript は実行しません。
必要な継承元や画像・フォントは、正規に入手したバニラ参照パックから読み込みます。
元パックは読み取り専用で、変更は別の書き出し先に保存します。

ファイル一覧で UI JSON を選び、さらにそのファイル内の定義を選択します。検索で
一覧を絞ることと、プレビューする定義を選ぶことは別です。Pocket は一覧・原文確認に
対応しますが、描画は `POCKET_PREVIEW_BLOCKED` で停止します。

## 編集

ホーム・編集・表示・データ・書き出し・診断から作業を選びます。プレビューの操作と
原文の編集は別のモードです。「編集」でパネル、ラベル、画像、ボタンを挿入できます。
選択要素をドラッグすると移動し、ハンドルでサイズ変更します。変数や式による寸法など、
自動変換できない構造は原文・属性側で編集します。

追加先は「選択要素の中へ」「同じ階層へ」を確認します。削除範囲や共有元の変更は
ほかの配置にも影響するため、適用範囲を確認します。生成されたセルに独立した原文が
存在しない場合は、そのセルだけを共有定義から切り離せるとは限りません。

草稿で見た目を確認し、「JSON UI に確定」で原文へ反映します。確定するまでは
元の ZIP を変更しません。元に戻す / やり直す操作を使えます。

## 状態とアニメーション

データからプレビュー状態を設定できます。ローカルの toggle、collection の状態、
指定時刻のアニメーションは、レンダラーがモデル化した範囲で評価します。
Minecraft のネイティブな screen controller、実際のコンテナ処理、サーバー応答、
入力受付順序まで実行するものではありません。

見た目を再描画できても、実機で受理されないプロパティ、解決が曖昧な binding、
ネイティブ処理が必要なボタンは診断を確認してください。親や要素の anchor と
ラベル内部の文字の縦位置は同じものではありません。未知プロパティを勝手に
実機の仕様として扱うことは避けます。

## 書き出し

ZIP の名前、パック表示名、対応する設定を確認して、別ファイルへ書き出します。
必要な素材や依存を含める設定は、それらの再配布許可を与えるものではありません。
[素材ポリシー](docs/release/ASSET_POLICY.md) を参照してください。

PNG 出力には対応する canvas 依存と必要な素材が必要です。素材不足や未対応描画が
残る場合、通常の strict 出力は完了と扱いません。`--allow-partial` で得た調査用画像は
不完全なプレビューであり、Minecraft と一致した画像とは呼びません。

## 診断と検証

「ログ」の診断バンドルには処理段階、時間、警告、解決状態などが記録されます。
共有前に、私的な名前・パス・パックの内容が含まれていないか確認してください。

公開ソースの検査は `npm run test:release`、公開する内容の確認は
`node scripts/release/audit-public.mjs` で実行します。公開版から除外した実機素材に
依存する歴史的テストは、公開版で成功したテスト数には数えません。
レンダラーで書き出して再びレンダラーで一致しても、それだけで実機一致にはなりません。

Windows の実起動、Minecraft の実描画・実入力について未検証の部分があります。
詳しい今回の実行結果と変更点は、ルート README および `docs/release/` を参照してください。
