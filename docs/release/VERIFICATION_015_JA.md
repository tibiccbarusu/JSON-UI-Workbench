# JSON UI Workbench 0.15.0 — 今回の変更と検証

この記録は、0.14.0 原本のコピーから CLI / API の入口を改良した今回の実行結果です。0.14.0 の過去の検証記録と合算していません。最終配布 ZIP の SHA-256、再ビルド一致、展開検査の結果は、納品時の別添「改良・検証報告」と証跡 ZIP に記録します。

## 対応した二つの問題

CLI を標準入口にしました。`npm start` は CLI の案内を表示して終了し、GUI を開きません。手で編集したい場合は `npm run gui` を使います。GUI は残し、初画面・タイトル・起動案内で実験版と表示します。`start.bat` / `start.cmd` / `start.sh` は従来の GUI 起動入口です。

Node API `createRenderer()` と、他言語向けのローカル HTTP API を追加しました。CLI 子プロセスを生成せず、CLI と共有の描画経路で検査・JSON / SVG / PNG 描画を行います。API の対象は読込み・一覧・検査・描画です。編集・履歴・パック書出しは CLI に残しています。[利用方法と契約](ENTRYPOINTS_JA.md)、[実行できる SDK 例](../../local-node/examples/api-preview.mjs) を参照してください。

## 安全性の確認範囲

- 公開モジュールの import だけでは、サーバー・Worker・ブラウザーを起動しません。
- API 要求を受け付ける時点で JSON データをコピーし、未知フィールド・getter・循環参照・危険なキー・非有限数・上限超過を拒否します。
- インスタンスごとに状態を分離し、最大 8 操作を直列処理します。取消・期限超過・終了を別々のエラーとして返します。
- 読込み応答の本文を読む前に取消しても、送信前に所有した upload ID と signal 無しの後片付けで登録を解放します。通常は旧パックを保持し、後片付けに失敗した場合は所有環境を閉じて再作成を要求します。
- API 所有のパックは再読込み・終了まで保持します。既存 CLI / GUI の idle 清掃は維持します。Worker 復旧時は明示的な再読込みが必要です。
- HTTP は `127.0.0.1` 限定です。Bearer token、Host / Origin 検査、本文・応答・接続数の上限を設けました。GUI と既存内部 API は公開しません。
- HTTP 接続ファイルは新規作成だけを許可し、終了時にも削除・書換えを行いません。他プロセスが置き換えたファイルの誤削除を避けます。停止後の token は使えません。
- API は原本の編集と描画ファイル保存を行いません。付属 SDK 例は既存の保護付き atomicWrite で PNG を新規保存します。
- 例外の公開 JSON に生の stack・cause・認証値を出しません。配布 manifest は hash / size に加え、実ファイルとの完全な集合一致を検査します。

最低 Node のスキップ 1 件は Windows 実 BAT 試験です。全体回帰のスキップはログにその理由を保持しています。非公開のゲーム素材を必要とする既存試験は公開版試験から除外し、成功件数に含めません。関連試験の再実行を全体回帰の件数へ加算していません。

実行で確認した代表例は、CLI / SDK の同一入力 PNG byte 一致、日本語文字・画像、型付き状態の適用、失敗 import の復元、同時インスタンスの分離、30 分超の仮想時計での API 保持、Worker 復旧後の再読込み、閉じた listener の接続不能、既存接続ファイルの上書き拒否です。最後に見つかった読込み取消の不具合も、繰り返し取消、旧パックの保持、応答 ID の誤り、404 不在、後片付け失敗時の閉鎖という 6 試験で修正を確認しました。
