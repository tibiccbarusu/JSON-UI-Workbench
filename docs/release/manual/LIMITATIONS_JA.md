# JSON UI Workbench 0.16.1 — 注意事項・対応範囲

English: [Limitations and cautions](LIMITATIONS_EN.md) · [説明書](USER_GUIDE_JA.md) · [仕様書](TECHNICAL_SPEC_JA.md)

この文書は、プレビューの結果から判断できること、判断できないことを説明します。対象は **Minecraft: Bedrock Edition の Classic JSON UI** です。対応する機能を、入力した状態と素材を使ってゲーム外で評価します。

## 1. Classic UI 専用・スマートフォン非対応

**本ツールはデスクトップ環境での Classic UI 開発用です。スマートフォンでのツール実行、Pocket UI・タッチ向け UI の描画や操作検証には対応していません。** Node.js とローカルファイルを扱えるデスクトップ環境を用意してください。

Pocket と判定された UI は一覧や原文の確認には使えますが、プレビューは `POCKET_PREVIEW_BLOCKED` で停止します。画面の幅や高さをスマートフォン相当に変えても、Pocket のレイアウト、タッチ入力、端末の安全領域などを再現することにはなりません。

ここでいう非対応は、このレンダラーの対象範囲です。Minecraft のモバイル版で Classic が選べるか、個別アドオンがモバイル版で動くかを、この制限だけから判定するものではありません。Classic/Pocket の選択と、端末や入力方法は別の条件として確認してください。

OreUI と、Script API の Data-Driven UI（DDUI）の実行・描画にも対応していません。`interact()` でローカルトグルを変化させられることは、DDUI の Observable やゲーム内のリアクティブなフォームを実行できるという意味ではありません。

## 2. 対応状況の一覧

「対応」は、記載した範囲の実装があるという意味です。「条件付き」は必要な入力・素材・対応する構造がある場合に利用できます。「非対応」は本ツールがその処理を提供しません。「未検証」は実装の有無とは別に、この版の検査で確認していない事項です。

| 対象 | 状況 | 範囲・条件 |
|---|---|---|
| Classic JSON UI の読込み・定義選択 | 対応 | ZIP / MCPACK / MCADDON 内のリソースパック。複数 RP や複数定義は明示的に選択します。 |
| JSON のフレーム出力 | 対応 | 評価したプロパティ、配置、診断を返します。画像素材を実際に描いた結果ではありません。 |
| SVG 出力 | 対応 | 配置・矩形を確認する診断図です。完成 UI やゲーム内の文字・画像描画とは異なります。 |
| PNG 出力 | 条件付き | 対応する canvas バックエンド、必要な画像・フォント・モデル、評価可能な状態が必要です。 |
| binding・collection・継承・生成要素 | 条件付き | 実装済みの式・生成規則と、与えた状態の範囲で評価します。ゲーム固有の全機構には対応しません。 |
| 指定時刻のアニメーション | 条件付き | 対応するトラックを絶対時刻でサンプリングします。ゲームの時計・実イベント順序は再現しません。 |
| `interact()` によるローカル状態変更 | 条件付き | 明示したノードへの `activate` / `escape` と対応する入力マッピング。適用する効果は `localTogglePatch` です。 |
| CLI / Node / HTTP からの音源解決 | 条件付き | 登録された短い OGG Vorbis / PCM16 WAV の参照・形式・ハッシュ等を返します。発音しません。 |
| 実験版 GUI の音声再生 | 条件付き | Node 接続と Web Audio を使用し、対応する短音の再生を試みます。ブラウザー側の許可・復号能力にも依存します。 |
| 原文編集・undo / redo・選択範囲のエクスポート | 条件付き | 安全に確定できる操作と依存関係が対象です。草稿、原文履歴、プレビュー状態は区別します。 |
| GUI による PowerPoint のような編集 | 実験機能 | 未完成です。共有定義・継承・生成要素の変更には制限があります。 |
| Pocket / タッチ UI のプレビュー | 非対応 | 索引・原文確認だけに対応します。 |
| スマートフォンでのツール利用 | 非対応 | デスクトップ Node.js 環境が対象です。 |
| OreUI / DDUI | 非対応 | OreUI のレンダリングや DDUI の Script API 実行機構はありません。 |
| Minecraft 本体・Behavior Pack スクリプトの実行 | 非対応 | 読み込んだ MCADDON の BP をゲームとして実行しません。 |
| 実際のインベントリ・クラフト・交易・アイテム移動 | 非対応 | 指定された模擬状態を表示できますが、所持品やゲーム世界を変更しません。 |
| ネイティブのフォーム送信・再開・サーバー応答 | 非対応 | 操作 API は対応する効果を記述できても、ゲーム側で実行しません。 |
| 全ブロック・全アイテム・全エンティティの完全な 3D 描画 | 非対応 | 個別の対応モデル・素材・プレビュー状態に限ります。 |
| この版での Minecraft 実機再比較・実音確認 | 未検証 | 内部の回帰検査と区別します。 |
| この版での Windows 実起動・ブラウザー実音出力 | 未検証 | Linux / Node の検査結果から自動的に合格とはしません。 |

## 3. 「成功」「complete」の意味

画像が保存されたこと、API が `ok: true` を返したことだけでは、実機で正しく動くとは判断できません。必要な品質軸と診断を確認してください。

| 項目 | 読み方 |
|---|---|
| `ok: true` | その API 処理を完了しました。Minecraft の動作合格ではありません。 |
| `complete` | PNG の素材・描画情報に関する完了です。アニメーション、発音、実機動作の包括的な保証ではありません。 |
| `preview_complete` | 対応範囲で資産・評価・collection・表示／入力 binding・記録済み非対応プロパティの検査が完了しました。 |
| `quality.animation` | 指定時刻のアニメーションを調べる独立した軸です。`preview_complete` だけで判断しないでください。 |
| `quality.native_properties` | 記録済みの不整合だけを確認します。全ネイティブスキーマへの適合を証明しません。 |
| `unknown` / `not_evaluated` | 確定できない、または検査していません。成功へ読み替えないでください。 |
| `draft: true` | 不足等を許容した調査用の結果です。完成した画面の証拠にはしません。 |
| `native_equivalence: 'not_evaluated'` / `native_parity_verified: false` | Minecraft 実機との一致をこの結果では証明していません。 |
| `playback: 'not_executed'` | 音源や再生要求の情報はありますが、その API は発音していません。 |

`--strict-semantics` は選択した投影の参照・評価・collection・表示／入力 binding・記録済みプロパティ等を厳格に検査します。`validate` はフレーム全体を評価するコマンドではなく、PNG も生成しません。アニメーションまで停止条件に含める場合は、プレビューに `--strict-animation` を指定してください。

通常の PNG は不足・非対応が残る場合に停止します。`--allow-partial` は調査用の部分描画を明示的に許可する指定で、実機互換性を高めるものではありません。`--strict-semantics` と `--strict-animation` の停止条件を解除する指定にもなりません。

## 4. 状態・操作・アニメーションの境界

フォーム、変数、コレクション、スクロール位置、時刻などは、呼出し側が与えたプレビュー状態です。ゲームから自動取得した最新状態とは限りません。実機でタイトル・本文・行・ボタン等が変わる場合は、必要な状態を変えて複数のプレビューを検査してください。

`interact()` は、フォームの記述と `uiInstanceId` を保ちながら、対応するローカルトグル状態を更新できます。ゲーム内でフォームを開閉しないまま入力が成功する証明ではありません。返された `localToggleState` を次の要求へ渡す必要があります。外部 binding が所有する状態をローカル保存状態で上書きしたり、別の UI の保存状態を混ぜたりしないでください。

`expectedRevision` は要求で渡した状態の番号との整合性を検査します。サーバーが最新状態を保管する方式ではないため、古い状態と古い番号を組にして再送することはできます。最新状態の保管や複数利用者の競合処理は呼出し側の役割です。

操作 API が実行する効果は `localTogglePatch` だけです。navigation、フォーム送信、clipboard 等の効果が記述されても、API が実行したとは扱わないでください。ドラッグやキーを連続再生してゲームの入力ループを再現する機能でもありません。GUI には個別の操作経路がありますが、API の効果記述と同一の実行範囲とは限りません。

アニメーションは、指定された時刻・イベント条件でのサンプルです。実機での画面生成、ネイティブ時計、イベントの順序、副作用、入力遅延、サーバーとの同期は未検証です。`uv` / `size` / `offset` に `looping` を持つ記録済みの組合せや、一部の `flip_book` 接続には互換性診断が残ります。数値を計算できても、この診断が消えるわけではありません。

## 5. OGG・WAV と発音の制限

登録済みサウンド ID を、読み込んだパックの音源へ解決します。`resolveSound()` は任意の OS ファイルを読む API ではなく、音声バイト列の返却やスピーカー再生も行いません。

対応する短音は **OGG Vorbis または PCM16 WAV、1 / 2 チャンネル、8,000～192,000 Hz、10 秒以内**です。さらに音源ファイル 4 MiB、復号後 PCM の予約量 8 MiB 等の制限があります。10 秒以内でも、予約量・パケット数・構造・その他の制限によって拒否される場合があります。

Opus、FSB、連結 OGG、長音のストリーム再生には対応しません。拡張子を `.ogg` に変えるだけでは Vorbis になりません。同じ音源名の OGG と WAV が曖昧になる場合は、サウンド定義で拡張子を明示してください。

GUI のブラウザー再生は、カテゴリ別の Minecraft 音量スライダーや 3D 位置音響を再現しません。該当する定義では `AUDIO_PREVIEW_CATEGORY_MIXER_NOT_APPLIED` / `AUDIO_PREVIEW_POSITIONAL_NOT_APPLIED` を報告します。候補の重み付き選択も、ゲームの乱数列と完全一致するとは限りません。合成 pitch の対応範囲は 0.5～2、出力 gain は 1 以下に制限され、GUI には別のプレビュー音量があります。

ブラウザーの音声許可、音声 OFF、音量 0、音源の準備時間、復号失敗、同時再生数・メモリ等で発音されないことがあります。音源の参照や形式検査に成功したこと、Web Audio に再生開始を要求できたことは、スピーカーから音が聞こえた証拠ではありません。この版ではブラウザー実音・実機実音の確認はしていません。

## 6. 画像・フォント・アイテム・3D モデル

公開ソースには Minecraft / Mojang のテクスチャ、フォント、音声、スキン、モデル、完全な UI を同梱しません。必要な継承元と素材は、対象のゲーム版に合い、利用権を持つ参照パックから読み込んでください。パックの優先順位、内容、文字言語、UI 倍率、描画寸法が変われば、結果も変わり得ます。

素材や必要な入力が欠けている場合は診断を返します。厳格 PNG は、足りない素材を無関係な画像で補って完成したと扱う機能ではありません。JSON / SVG の配置だけが得られても、PNG の最終文字測定・再配置や、ゲームの字体・レイヤー順と同じになるとは限りません。

アイテムの数値 ID 表は対象版に依存します。独自アイテム、補助データ、NBT、染色、エンチャント、動的な表示等の全状態には対応していません。モデルが必要な品目で `NATIVE_ITEM_MODEL_REQUIRED` が出たら、面テクスチャを完成アイコンと読み替えないでください。

対応する player / horse 等のモデル経路があっても、全エンティティのゲーム描画機構ではありません。player は参照パックのモデル・スキンを使い、利用者のアカウントスキンを自動取得しません。実装したカメラ・材質・controller・状態の範囲外は、診断または未対応として扱います。

## 7. 診断は限定された互換性検査

現在の記録済みプロパティ診断には、次のような対象があります。

| 記述 | 診断の範囲 |
|---|---|
| `label.vertical_alignment` | 記録済みのネイティブ拒否。原文には残し、プレビューの縦配置には使用しません。 |
| 受動的な `panel` / `image` の `focus_enabled` | `false` を含め、プロパティの存在を診断します。入力可能なすべての型を禁止する規則ではありません。 |
| `collection_index` と具体的な直近親の不整合 | 行所有権・親文脈の限定された検査です。単独テンプレートや全 collection 読取りを一律に禁止しません。 |
| 特定アニメーション型の `looping` 等 | アニメーション品質で互換性不明を記録します。すべての `looping` や `flip_book` を禁止しません。 |

未知のプロパティを包括的に禁止する完全なスキーマ検査ではありません。診断が出ないことだけから、未来のゲーム版を含む全プロパティが有効とは判断できません。

binding の全体検索による候補解決、collection の文脈不足等も、計算成功とは別の注意を返す場合があります。走査や診断の観測上限に達したときは `unknown` / 観測不完全を示します。省略された診断があることを「問題なし」と扱わないでください。

## 8. 大きな UI・編集・出力の注意

ノード数、生成数、入れ子、描画矩形、画像メモリ、要求時間、応答量等に制限があります。主要な例はモデル 50,000 ノード、PNG 5,000 矩形、PNG 一辺 8,192 px・総画素 16 Mi ピクセル、フレーム応答 24 MiB です。これはレンダラーの予算であり、Minecraft の UI 上限や FPS の保証ではありません。上限の全一覧と適用箇所は[仕様書](TECHNICAL_SPEC_JA.md)を参照してください。

`--frame-summary` は大きなフレームの概要を JSON で受け取るための指定です。完全な診断本文・描画可能なフレーム・PNG を返さず、生成や評価の上限も解除しません。画面を分割して検査する場合は、部分ごとの成功を全画面の合格に置き換えないでください。

実験版 GUI の編集では、同じ共有定義を使う複数の要素が影響を受ける場合があります。生成セルには独立した原文がない場合もあります。移動・削除・継承解除を常に任意の一要素だけへ適用できるわけではありません。草稿の確認、原文への確定、エクスポートを区別してください。

原文の undo / redo は無制限ではなく、プレビューのクリック状態、設定変更、UI 選択をすべて戻す機能でもありません。CLI の原文履歴は最大 64 件 / 8 MiB で、セッション全体にも上限があります。履歴が削除された場合や大きすぎる単一編集では取り消せないことがあります。

元アーカイブを変更せず、別の出力へ保存する設計です。ただし、書き出したファイルが意図した内容かは、原文・診断・再読込みで確認してください。出力先の上書き保護を回避して入力と同じ場所へ保存する使い方はしないでください。

## 9. 公開前に確認すること

1. 対象ゲーム版、Classic プロファイル、入力方法、参照パック、言語、寸法・UI 倍率を記録します。
2. 開いた直後だけでなく、ボタン・トグル・行・スクロール・アニメーション時刻を変えた必要な状態を検査します。
3. 検査したい範囲に厳格オプションを適用し、`quality`、不足、`unknown`、部分描画の有無を確認します。
4. ゲーム内での表示・入力・フォーム返却・スクリプト・インベントリ・音声は、必要に応じて Minecraft と Content Log で別に確認します。
5. 配布するコード・素材と、公開する診断ファイルの内容を確認します。診断にはパックの内容・名前・ローカルパス等が含まれ得ます。

この確認は、レンダラーの出力から言える範囲と、ゲーム内で確認する範囲を整理するためのものです。
