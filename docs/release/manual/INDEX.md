**Classic UI 専用です。Pocket・タッチ向け UI の再現と、スマートフォン上での本ツールの利用は非対応です。** GUI の編集は実験版です。正式な [ライセンス原文](../legal/PolyForm-Noncommercial-1.0.0.md) を変更せず同梱し、日本語で各条項を説明しています。商用目的の利用は許可しません。

**Classic UI only. Pocket/touch UI reproduction and use of this tool on smartphones are unsupported.** GUI editing is experimental. The unchanged [governing license](../legal/PolyForm-Noncommercial-1.0.0.md) is included, with equivalent explanations in both languages. Commercial purposes are not permitted.

`examples/` の教材の実行には、文書だけの ZIP ではなく、完全なソース ZIP を展開した作業フォルダーを使います。HTML は単独で開いて本文を読めます。別ファイルへの補助リンク・教材は配布 ZIP の中にあります。

Run `examples/` from the complete source distribution, rather than the documentation-only ZIP. The HTML handbook can be read as a standalone file; supplementary linked files and tutorial sources are included in the ZIP distributions.

現行の動作・対応範囲は本案内の説明書・仕様書・注意事項を優先します。旧 CLI 詳細や入口ガイドは補助資料、版別の検証報告は当時の実行記録です。0.16.1 は文書・ライセンス整備版で、レンダラーの動作実装は 0.16.0 から変更していません。

The guides linked here define current behavior and scope. Legacy CLI and entry-point documents are supplementary; versioned verification reports describe historical runs. Version 0.16.1 updates documentation and licensing while preserving the 0.16.0 rendering implementation.
